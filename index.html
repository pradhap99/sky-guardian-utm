🛰️ Sky Guardian UTM

Enterprise-Grade Unmanned Traffic Management for BVLOS Drone Operations

What is Sky Guardian?

Sky Guardian is a comprehensive SaaS platform designed for managing multi-operator Beyond Visual Line of Sight (BVLOS) drone operations. It provides real-time airspace deconfliction, automated jurisdictional compliance, and streamlined regulator approval workflows.

Core Features

🎯 Real-Time Risk Scoring

Evaluate flight risk across Air, Ground, and Operational dimensions with live calculations.

📍 4D Conflict Detection

Detect and prevent spatial/temporal collisions with sub-100ms latency.

✅ Automated Compliance

Enforce jurisdiction-specific regulations automatically.

👨‍💼 Regulator Portal

Enable civil aviation authorities to review and approve flights efficiently.

🗺️ Interactive Mapping

Visualize flight corridors and airspace reservations on an interactive map.

📊 Analytics & Audit

Complete tracking of all decisions and actions for compliance.

Technology Stack

Frontend: React 18, TypeScript, Leaflet
Backend: Node.js, Express, Microservices
Database: PostgreSQL, PostGIS
Deployment: Kubernetes, Docker, Terraform

🚀 Get Started

Clone the repository:

git clone https://github.com/pradhap99/sky-guardian-utm.git

Setup & Run:

  • Backend: cd backend && npm install && npm run dev
  • Frontend: cd frontend && npm install && npm start
  • Open: http://localhost:3000
